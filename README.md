# cmce-exam
## CDAC PGCP-AC · Java 17 Core Java MCQ Practice Bank

An interactive, responsive web application for CDAC PGCP-AC Core Java (Java 17) MCQ exam preparation.

### 🌟 Features
- **200 Curated MCQs**: Questions covering 12 core Java sections (OOP, Generics, Lambdas, Streams, Multithreading, Records, Pattern Matching, Sealed Classes, JDBC, etc.).
- **Multiple Quiz Modes**:
  - Full Test (all 200 questions)
  - By Section (pick specific topics)
  - Quick 50 (50 random questions)
  - Traps Only (focus on tricky questions)
- **Instant Answer Feedback**: Explanations with correct answers immediately upon selection.
- **Detailed Analytics**: Score breakdown, percentage calculation, and section-wise performance tracking.
- **Review Mode**: Complete post-test review comparing chosen options vs. correct answers with full explanations.
- **Keyboard Shortcuts**: `1-4` for answering, `Arrow Keys` or `Enter` for navigation.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with dark glassmorphic UI.

### 🚀 Getting Started
Simply open `index.html` in any modern web browser — no web server or build process required.
